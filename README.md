# Luma Noire Photography Website Starter

A lightweight, responsive starter website built for GitHub Pages.

## Included

- Home, Glamour, Family, Portfolio, About, Investment, FAQ, Contact, and 404 pages
- Responsive navigation
- Portfolio filtering and lightbox
- Scroll reveal animation
- SEO metadata, sitemap, robots.txt, and favicon
- Accessible semantic HTML
- Placeholder SVG images that can be replaced with your photography
- Formspree-ready contact form

## Publish with GitHub Pages

1. Extract the ZIP.
2. Copy all files into the root of your GitHub repository.
3. Commit and push the files.
4. Open your repository settings.
5. Select **Pages**.
6. Set the source to **Deploy from a branch**.
7. Choose the `main` branch and `/root` folder.
8. Save.

## Replace Before Launch

Search the project for these placeholders:

- `https://www.lumanoirephotography.com`
- `hello@lumanoirephotography.com`
- `YOUR_FORM_ID`
- `Starting at $___`
- Instagram `href="#"`

Replace the SVG files in `images/placeholders/` with your finished web-optimized images. You can keep the same filenames to avoid editing the CSS.

## Image Recommendations

- Hero images: 2400 × 1600 pixels
- Feature cards: 1400 × 1800 pixels
- Portfolio images: 1400 × 1800 pixels
- Social preview: 1200 × 630 pixels
- Export JPEG or WebP at approximately 70 to 85 percent quality

## Contact Form

Create a free Formspree form and replace `YOUR_FORM_ID` in `contact.html`.

## Custom Domain

After connecting a custom domain in GitHub Pages, update the canonical URLs in every HTML page, plus `sitemap.xml` and `robots.txt`.
